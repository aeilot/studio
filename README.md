# Evolution Studio

Site for Evolution Studio, built with [Next.js](https://nextjs.org/).

## Development

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Projects

Featured projects are defined in `lib/projects.ts` and shown on the homepage.

## Build

```bash
pnpm build
pnpm start
```
